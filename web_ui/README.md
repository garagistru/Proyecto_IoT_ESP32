# 🕷️ Web UI: EnrollaDatos (ED) Monitoring

Этот модуль представляет собой адаптивный веб-интерфейс для мониторинга состояния сети узлов (Nodos) в проекте Proyecto_IoT_ESP32.

Интерфейс разработан по принципу **Mobile-First** и оптимизирован для корректного отображения как на маленьких экранах (240x320px, дисплей устройства), так и на смартфонах и десктопах оператора.

---

## 📁 Структура файлов

Мы используем принцип **разделения ответственности** (Separation of Concerns), чтобы код был чистым, читаемым и легко масштабируемым:

```text
web_ui/
├── index.html          # Скелет приложения (разметка DOM)
├── css/
│   └── style.css       # Внешний вид (CSS-переменные, адаптивность, анимации)
├── img/
│   └── rojo_spider.png # Графический элемент статуса
└── js/
    ├── config.js       # ⚙️ Конфигурация: URL, тайминги, значения по умолчанию
    ├── state.js        # 🧠 Состояние: единое хранилище данных (State Management)
    ├── api.js          # 📡 Сеть: абстракция запросов к ESP32 (Fetch API)
    ├── ui.js           # 🎨 Отображение: работа только с DOM-элементами
    └── app.js          # 🎼 Контроллер: главный дирижер, связывающий всё воедино
```
