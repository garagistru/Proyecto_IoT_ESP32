# Узел "mesa_6" — ESP32-C6 с OLED и кнопками

**Версия прошивки:** v3.6
**Дата:** 2026-09-24
**Плата:** ESP32-C6 SuperMini
**Порт:** USB Serial (COM8, 115200)

---

## 📋 ОПИСАНИЕ

Удалённый узел сбора данных для системы **EnrollaDatos (ED)**.

Считает нажатия кнопки COUNT во время активной смены, ведёт счёт смен,
отправляет данные на головное устройство (ESP32-S3) по Wi-Fi.

---

## 🧩 ФУНКЦИОНАЛ

| Компонент    | GPIO   | Описание                                      |
| ------------ | ------ | --------------------------------------------- |
| **COUNT**    | GPIO14 | Счётчик действий (INPUT_PULLUP)               |
| **SHIFT**    | GPIO15 | Тумблер смены (INPUT_PULLUP, фиксируемый)     |
| **REBOOT**   | GPIO9  | Кнопка перезагрузки (INPUT_PULLUP, сервисная) |
| **OLED SDA** | GPIO4  | I2C данные                                    |
| **OLED SCL** | GPIO5  | I2C такты                                     |
| **OLED VCC** | 3.3V   | Питание дисплея                               |
| **OLED GND** | GND    | Общий                                         |

⚠️ **НЕ использовать:**

- **GPIO8** — strapping boot pin (загрузка)
- **GPIO10** — отсутствует на SuperMini

---

## 🧠 ЛОГИКА РАБОТЫ

1. **Смена началась** → SHIFT замкнут (LOW)
   - Отправляется `/status` с `abrir`
   - На OLED: `ACTIVO` + счётчик + время работы
   - COUNT начинает считать нажатия

2. **Смена идёт** → COUNT нажат
   - `pressCount++`
   - Каждые 10 нажатий — сохранение в NVS

3. **Смена завершилась** → SHIFT разомкнут (HIGH)
   - Отправляется `/status` с `cerrado`
   - Пакет смены кладётся в очередь NVS
   - `shiftNumber++`, `pressCount = 0`

4. **Отправка данных** — раз в 30 сек, если очередь не пуста
   - 1 пакет за раз
   - При `HTTP 200` пакет удаляется из очереди

## 📡 ФОРМАТ ОТПРАВЛЯЕМЫХ ДАННЫХ

### `POST /data` (завершённая смена)

**Content-Type:** `application/x-www-form-urlencoded`

| Поле               | Пример         | Описание                     |
| ------------------ | -------------- | ---------------------------- |
| `mac`              | `10BDA3ACE668` | MAC-адрес узла (12 hex)      |
| `name`             | `meSa-6`       | Имя станка                   |
| `actions`          | `145`          | Нажатий за смену             |
| `start`            | `08:15:00`     | Время начала смены           |
| `end`              | `16:45:30`     | Время окончания смены        |
| `time_source`      | `gateway`      | `gateway` / `uptime` / `ntp` |
| `event_duration_s` | `30630`        | Длительность смены, сек      |
| `sensor_uptime_s`  | `86412`        | Uptime узла, сек             |
| `boot_id`          | `3D8A29F1`     | ID текущей загрузки (8 hex)  |

### `POST /status` (сигнал смены состояния)

nombre=meSa-6&status=abrir
nombre=meSa-6&status=cerrado

text

⚠️ Здесь поле `nombre` (не `name`). Это унаследовано от ESP8266 и **не должно переименовываться**.
