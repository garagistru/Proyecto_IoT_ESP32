# 🟢 Узел "mesa_6" — ESP32-C6 с OLED и кнопками

## 📋 ОПИСАНИЕ

Прошивка для **ESP32-C6**, которая работает как **удалённый узел сбора данных** в системе EnrollaDatos (ED).

Устройство предназначено для:

- **Подключения к сети Wi-Fi** `Mechanic`
- **Регистрации** на головном устройстве (ESP32-S3)
- **Отправки данных** о нажатиях и сменах через HTTP POST
- **Отображения статуса** на OLED-дисплее (128x64)

---

## 🧩 ФУНКЦИОНАЛ

| Функция                   | Описание                                                          |
| ------------------------- | ----------------------------------------------------------------- |
| **Кнопка COUNT (GPIO14)** | Счётчик действий. Работает только в активной смене.               |
| **Кнопка SHIFT (GPIO18)** | Включение/выключение смены (фиксируемая кнопка/тумблер).          |
| **OLED-дисплей (128x64)** | Отображает: статус, счётчик, время, иконку Wi-Fi, символ питания. |
| **Wi-Fi**                 | Подключается к сети `Mechanic`.                                   |
| **HTTP-клиент**           | Отправляет данные на сервер `http://192.168.4.1`.                 |
| **Preferences (ESP32)**   | Сохраняет состояние смены и счётчик после перезагрузки.           |

---

## 🧠 ЛОГИКА РАБОТЫ

1. **Смена активна** → кнопка SHIFT замкнута (LOW).
   - Счётчик нажатий увеличивается.
   - На OLED отображается **количество нажатий** и **время работы**.
   - Отправляется сигнал `abrir` на головное устройство.

2. **Смена завершена** → кнопка SHIFT разомкнута (HIGH).
   - Смена завершается, данные (время, количество нажатий) сохраняются в буфер.
   - Отправляется сигнал `cerrado`.
   - Номер смены увеличивается.

3. **Отложенная отправка** — данные отправляются на сервер фоново, каждые 15 секунд (если есть данные в буфере).

4. **Автосохранение** — каждые 10 нажатий состояние сохраняется в энергонезависимую память.

| Компонент        | Пин ESP32-C6 | Примечание           |
| ---------------- | ------------ | -------------------- |
| **OLED SDA**     | GPIO19       | I2C                  |

## ⚠️ ВАЖНЫЕ ОСОБЕННОСТИ ПРОШИВКИ

### 1. Платформа: ESP32-C6

- **Arduino IDE** — прошивается через Arduino IDE (PlatformIO пока не поддерживает ESP32-C6 с Arduino-фреймворком).
- Ядро должно быть обновлено до последней версии, поддерживающей ESP32-C6.

### 2. Версия ядра ESP32

Для прошивки ESP32-C6 через Arduino IDE необходимо установить ядро **v3.0.0 или выше** (поддерживает ESP32-C6).
Установка через менеджер плат (Board Manager URL: `https://espressif.github.io/arduino-esp32/package_esp32_index.json`).

### 3. Особенности кнопки SHIFT

Кнопка SHIFT — **фиксируемая** (тумблер, не тактовая). При замыкании смена активна. При размыкании — смена завершается.

### 4. Сохранение состояния

- Используется `Preferences` — встроенная энергонезависимая память ESP32.
- При включении состояние восстанавливается.

### 5. Очередь отправки

Данные не отправляются мгновенно. Они сохраняются в очередь до 10 записей и отправляются фоново (каждые 15 секунд).

## 🛠️ ПРОШИВКА (Arduino IDE)

1. Откройте **Arduino IDE**.
2. Выберите плату: `ESP32C6 Dev Module`.
3. Настройте порт (например, COM8).
4. Установите скорость: 115200.
5. Нажмите **Upload**.

**Важно:** Если плата не определяется, установите драйвер для CH340 / CP210x.

## 📊 ФОРМАТ ОТПРАВЛЯЕМЫХ ДАННЫХ

### Статус смены

```http
POST /status
nombre=mesa_6&status=abrir
```

Данные смены
http
POST /data
nombre=mesa_6&temperatura=1&humedad=42
где:

temperatura — номер смены,

humedad — количество нажатий.

🧪 ПРОВЕРКА РАБОТЫ
OLED-дисплей — отображает статус.

Wi-Fi — иконка activo при подключении.

Кнопки — реакции на нажатия.

Веб-интерфейс — на http://192.168.4.1 появляется устройство mesa_6.

Сервер Ubuntu — в ~/data/sensor_data.json появляются записи.

🐞 ЧАСТЫЕ ПРОБЛЕМЫ
Проблема Решение
OLED не работает Проверьте I2C адрес (0x3C), SDA/SCL пины.
Wi-Fi не подключается Проверьте пароль, убедитесь, что ESP32-S3 создаёт сеть Mechanic.
Ошибка при компиляции Установите последнюю версию ядра ESP32 через менеджер плат.
Платформа не определяется Установите драйвер CH340/CP210x для USB-порта.
